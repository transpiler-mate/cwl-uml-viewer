# How-to guides

Use these guides when you have a specific task:

- [Configure previews](configure.md): executable paths, output format, timeout, and remote hosts.
- [Manage vendor dependencies](dependencies.md): rebuild Python packages or update PlantUML.
- [Troubleshoot rendering](troubleshoot.md): diagnose loading and renderer errors.
- [Develop and package](develop.md): run checks, debug, and produce a VSIX.
- [Build the documentation](documentation.md): preview, validate, and maintain this site.

For a guided introduction, start with [Your first diagram](../tutorials/first-diagram.md).
