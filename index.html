CWL UML¶

CWL UML is a desktop VS Code extension that turns CWL workflows into UML previews. It loads a workflow model, generates PlantUML, and renders an image locally without running the workflow.

Python libraries and the ASL PlantUML JAR are already supplied under vendor/. Install Python and Java on the extension host; use a Python interpreter compatible with the bundled native modules.

This documentation follows Diátaxis, separating learning, practical tasks, technical facts, and explanations.
